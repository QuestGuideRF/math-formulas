# Сборник формул по математике

![Preview](img/preview.png)

## Описание

Это - сборник формул по математике и смежным дисциплинам. Он написан в формате `.tex`, но его можно скомпилировать в `.pdf` файл, либо из этого файла составить картинку, которую можно распечатать и заламинировать.

Здесь, конечно же, не будут собраны формулы все до единой, а только те, которые используются чаще всего, показывают некоторые нюансы, либо могут ускорить решение задачи. Так же будет соблюдаться принцип `минимальной необходимой информации для вывода` - будет написано столько информации, чтобы за один шаг логического вывода можно было получить всё необходимое.

## Компиляция

### Установка программы

**Для пользователей Windows:**
- Скачиваем TeX Live с [официального сайта](https://www.tug.org/texlive/)
- Устанавливаем полную версию (Full Scheme)

**Для пользователей Linux:**
```bash
sudo apt install texlive-full
```

**Для пользователей macOS:**
```bash
brew install --cask mactex
```

### Компиляция документа

В папке, где находится файл `main_file.tex`, в командной строке выполните:

```bash
xelatex main_file.tex
```

Вы получите `main_file.pdf`. Если возникнут ошибки, запустите команду дважды для правильной генерации ссылок и оглавления.
